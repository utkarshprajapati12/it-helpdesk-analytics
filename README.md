# IT Helpdesk Ticket Analytics

Analysis of 1,000 IT support tickets to find SLA breaches, slow categories and agent performance.

**Tools:** Python (pandas), SQL (SQLite)

## Problem
An IT support team wants to know which ticket types take longer than the SLA, which agents need support, and how many tickets are still open.

## What I did
1. Cleaned the ticket data and calculated resolution time for each ticket (`analyze_tickets.py`).
2. Checked each ticket against its priority SLA (Critical 4h, High 8h, Medium 24h, Low 72h).
3. Ran 6 SQL queries for KPIs, priority, category, agent, monthly volume and open tickets (`queries.sql`).

## Key findings
- VPN / Remote access and Slow computer tickets breach SLA the most.
- Password reset and Printer tickets are always resolved within SLA.
- Critical tickets breach SLA about 34% of the time, which is the top risk for the team.

## How to run
```bash
pip install pandas
python generate_tickets.py
python analyze_tickets.py
```

## Files
- `tickets.csv`: sample data (1,000 tickets)
- `generate_tickets.py`: creates sample data
- `analyze_tickets.py`: cleaning, SLA check, SQL queries
- `queries.sql`: SQL queries

Note: the data is synthetic, generated by the script.
